Project Name

Start Date

23/02/2021

End Date

Project Summary

Con el proyecto se busca brindar acceso a agua segura para consumo humano, adecuar, rehabilitar o construir infraestructura o sistemas de almacenamiento y distribución de agua, acciones de monitoreo y calidad de agua las condiciones, así como fortalecimiento a las capacidades comunitarias mediante comités de agua y prácticas claves de higiene.
