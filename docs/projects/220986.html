Project Summary

Este proyecto se centra en aumentar las capacidades de las comunidades para la gestión de incendios forestales, con un doble enfoque en la vigilancia y la prevención. Incluye actividades de capacitación teórico-prácticas que enseñan a los miembros de la comunidad cómo vigilar, reportar y verificar incendios de manera oportuna. Además, se proporcionan kits de elementos esenciales para reforzar el monitoreo comunitario y se establecen protocolos para el seguimiento de reportes y verificaciones de incendios. El proyecto también contempla la supervisión general de estas actividades y capacita a las comunidades en prácticas de prevención de incendios forestales para mitigar su ocurrencia.
