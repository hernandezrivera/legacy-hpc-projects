Project Summary

Las zonas priorizadas por este proyecto sufren una doble afectación por cuenta de la violencia
que ejercen varios grupos armados organizados y de las emergencias causadas por desastres
naturales. Estas condiciones aumentan los riesgos de protección para las comunidades
priorizadas. Por esta razón, se propone una intervención social con actividades de
fortalecimiento comunitario y prácticas de mitigación de riesgos, tanto a nivel local como
regional.
