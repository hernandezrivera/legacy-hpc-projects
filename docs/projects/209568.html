Project Summary

El proyecto fortalecerá y vinculará a las organizaciones a nivel comunitario, (Escuelas de Campo Agrícolas, los GAAP y COLRED) para crear la resiliencia y la cohesión social de las comunidades participantes, así como para conectar a estas organizaciones con los proveedores de servicios privados de última milla y con las estructuras del gobierno municipal para la prestación sostenible de servicios de calidad. Promoverá ferias agrícolas y pecuarias para la diversificación nutricional y otorgará transferencias de efectivo multipropósito a hogares vulnerables.
