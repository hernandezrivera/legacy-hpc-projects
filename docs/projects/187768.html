Project Summary

Provisión de insumos y servicios para favorecer la movilidad y rehabilitación de personas
con discapacidad. Dentro de las principales actividades destacan la contratación de
personal para brindar terapias ocupacionales y otro tipo de tratamientos clave para lo
rehabilitación, personal para la prescripción adecuada de los aditamentos o insumos para
la movilidad, su adaptación y aprovisionamiento apropiado, cobertura de los costos
totales de terapias para pacientes, entrega de equipo de bioseguridad para terapistas,
entrega de sillas de ruedas, bastones, andaderas, entre otros; para garantizar su goce de
derechos de salud. Este proyecto será ejecutado entre agosto 2021 y diciembre 2022.
