Start Date

End Date

Project Summary

Conformación o consolidación de espacios territoriales para la preparación y respuesta a situaciones de emergencias, idealmente liderados o coliderados por las autoridades gubernamentales. Incluyen acciones para manejo de información, monitoreo de la respuesta, creación o mejoramiento de planes de contingencia y fortalecimientos a las autoridades territoriales. También incluye acciones de dotaciones a autoridades locales que no se pueden contabilizar con beneficiarios.
